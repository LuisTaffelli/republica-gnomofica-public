# Preparación de esta muestra

La copia se construyó seleccionando archivos de código y documentación, sin
copiar el árbol completo ni usar un export del historial de Git.

El perfil de ejemplo se escribió desde cero. No contiene memorias iniciales.
Los textos de pruebas son fixtures; el nombre de la persona y las referencias
de salud de esas fixtures se sustituyeron por valores de ejemplo. La atribución
de la licencia se presenta con el nombre del proyecto.

No se incluyeron archivos de entorno, credenciales, bases de datos, conversaciones,
recuerdos privados, logs, capturas, rutas del equipo original ni resultados de
experimentos. La bitácora de esta copia sólo describe su preparación pública.

La revisión automatizada busca identificadores personales conocidos, correos,
rutas de usuario, claves con formatos reconocibles y archivos excluidos. Esa
revisión tiene un alcance concreto: no constituye una garantía universal de
anonimización frente a cualquier inferencia a partir del estilo o las ideas.

Ejecutar la aplicación puede generar datos nuevos. No publiques `data/`, `.env`,
logs ni un historial de Git creado posteriormente sin una nueva revisión.
