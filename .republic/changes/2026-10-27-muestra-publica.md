# Preparar una muestra pública con datos sintéticos

Se seleccionaron archivos de código y documentos conceptuales, excluyendo
historial, almacenamiento, credenciales, campañas y configuración del equipo.
Se creó un perfil genérico y una demo conversacional sin red. Se neutralizaron
referencias personales en código y fixtures, manteniendo coherentes los tests.
Los runners históricos de evaluación delegada y sus cuatro módulos de tests
no forman parte del alcance de esta muestra.

La instalación limpia, las demos y la ayuda del entrypoint funcionaron.
Pasaron 949 tests Python, 43 subtests y 23 tests JavaScript; cuatro tests
Python se omitieron por plataforma o versión de CPython.

README, PRIVACIDAD y VERIFICACION explican instalación, límites y alcance.
No se modificó el canon ni se activó un servicio público. El perfil ficticio
y la etiqueta genérica del humano pertenecen sólo a esta distribución.
