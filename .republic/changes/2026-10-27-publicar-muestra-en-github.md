# Publicar la muestra sintética en GitHub

El propietario autorizó subir esta muestra al repositorio público indicado.
Se verificó que el destino estaba vacío y que los 146 archivos coincidían
con el ZIP revisado. Se repitió la búsqueda de identificadores personales,
correos, rutas de usuario y formatos reconocibles de claves, sin hallazgos.

Se creó un historial Git nuevo, sin importar el historial privado. La autoría
del commit usa el nombre del proyecto y una dirección genérica para evitar
publicar un correo personal. Se corrigieron cuatro detalles de espacios en
blanco detectados por git diff --cached --check.

La evidencia funcional sigue siendo la registrada en VERIFICACION.md:
949 tests Python, 43 subtests y 23 tests JavaScript aprobados; cuatro tests
omitidos por plataforma o versión. No se cambió comportamiento, arquitectura
ni canon. No se desplegó un servicio. Esta bitácora registra el alcance y los
controles de la publicación; el estado remoto se verifica después del push.
